# Segmentor - Editor de Vídeo para Windows

## 📌 Visão Geral
O **Segmentor** é um editor de vídeo desenvolvido em **Python compactado** e otimizado para **Windows**.  
Seu objetivo é simplificar a segmentação e edição de vídeos com **eficiência**, **leveza** e **facilidade de uso**, sem depender de instalações externas além do **FFmpeg**.

---

## ⚙️ Recursos Principais
- ✂️ **Segmentação automática e manual** de arquivos de vídeo  
- 🎬 **Suporte a múltiplos formatos**: MP4, AVI, MKV, MOV  
- 🔄 **Processamento em lote** de múltiplos vídeos  
- 👀 **Pré-visualização em tempo real**  
- ⏳ **Barra de progresso integrada**  
- ⌨️ **Atalhos de teclado personalizáveis**  
- 📂 **Organização automática de arquivos de saída**  

---

## 💻 Requisitos do Sistema
- **Windows 10 ou superior (64 bits)**  
- **Python 3.8+ compactado** (já incluso no repositório)  
- **FFmpeg 4.4+** (necessário no PATH do Windows)
